# Create task

From the repository root run `./agentflow create "$ARGUMENTS"` on POSIX or `.\agentflow.ps1 create "$ARGUMENTS"` on Windows. Ask only for a missing title; checkpoint defaults to CP1. Report the created task ID and do not start it.
