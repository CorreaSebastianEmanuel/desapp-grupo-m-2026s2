# ADR-0010: Generate the CP1 Acceptance Record for the Exact Revision

**Status**: Accepted

**Date**: 2026-09-29
**Scope**: TASK-015 CP1 acceptance evidence

## Context

CP1 acceptance must identify one candidate revision and correlate every result to it. Committing a completed record containing its own commit SHA is circular, while a working-tree snapshot or older hosted run cannot establish final acceptance. Manual aggregation can also claim PASS despite missing or stale evidence.

## Decision

Commit a declarative ten-obligation manifest, not a manually asserted verdict. A fail-closed evaluator generates authoritative JSON and human-readable Markdown after checkout, binding receipts to the full candidate SHA. Working-tree and PR runs are preflight. The final record is generated by the integrated `main` workflow after all checks, including the exact-revision governing Sonar analysis, complete. It is published as a SHA-named GitHub Actions artifact and run summary without modifying the candidate commit.

Only ten passing, safe, accessible, published, same-SHA entries yield PASS. Missing, malformed, stale, mixed-revision, unsafe, or unavailable evidence is non-passing.

## Consequences

- The acceptance record is reproducible without self-modifying source history.
- Final checkpoint acceptance occurs after merge; feature-branch evidence cannot be mislabeled final.
- Normal GitHub authorization and artifact retention apply. Repository documentation must provide stable navigation; a requirement for longer permanence would need a separate storage decision.
- The evaluator and manifest become checkpoint tooling only and do not enter application architecture.

## Rejected alternatives

- Commit the generated record: every update changes the revision it claims to describe.
- Accept a dirty-tree fingerprint as final: contradicts committed candidate requirements.
- Hand-edit PASS or copy earlier green runs: cannot guarantee completeness or freshness.
- Add an external evidence database/service: unnecessary infrastructure for CP1.
