## Implementation Strategy

1. Deliver US1 alone as the smallest independently testable catalog-filter increment.
2. Add combined AND filters in US2 while retaining all US1 tests.
3. Add the full cursor and security matrix in US3 while retaining US1 and US2 tests.
4. Run routine checks and the separate fixed SC-006 measurement. If the latency gate fails, retain the failing evidence, inspect the actual ordered filtered query plans, and add an index migration only when before/after measurements justify it. Do not lower the threshold or narrow the matrix.
